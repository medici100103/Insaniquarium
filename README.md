# Aqua Guppy · 구피의 작은 바다

`Design.txt`와 `Images/`의 24개 이미지를 바탕으로 만든 수족관 육성 웹게임입니다. `game-plan.md`와 `game-design.md`는 현재 구현을 반영한 기획서·개발 설계서입니다.

## 실행

**`index.html`을 Chrome 또는 Edge에서 여세요.** 설치, 빌드, 인터넷 연결, 서버 없이 실행됩니다. 폴더를 옮길 때는 `index.html`, `css/`, `js/`, `Images/`, `Sounds/`를 함께 옮겨 주세요.

게임은 이미지 준비가 끝나면 1-1에서 바로 시작합니다. 처음에는 $100, 배고픈 아기 구피 2마리, 사료 상한 3개가 주어집니다. 저장 기능은 없으며 새로고침하면 처음부터 시작합니다.

## 조작

| 조작 | 동작 |
| --- | --- |
| 수족관 빈 곳 클릭 / 터치 | $5를 내고 사료 주기 |
| 동전·보석·진주 클릭 / 터치 | 재화 획득 |
| 상단 상점 클릭 | 구피, 사료 확장, 피라냐, 알 조각 구매 |
| 에일리언 클릭 / 터치 | 체력 1 감소, 앞쪽을 클릭하면 넉백 |
| Space / 배속 버튼 홀드 | 누르는 동안 개발용 3배속, 놓으면 1배속 |
| P / 일시정지 버튼 | 일시정지 ↔ 계속 플레이 |
| 스피커 버튼 | 배경음·효과음 함께 켜기 / 끄기 (기본: 켜짐, 첫 클릭이나 키 입력 후 재생) |
| 플레이 가이드 | 게임을 멈추고 상세 설명 열기 |

다른 탭으로 이동하면 자동으로 일시정지합니다. 돌아온 뒤 **계속 플레이**를 누르세요. 모바일은 가로 화면을 권장합니다.

개발용 배속은 스페이스바 또는 화면 버튼을 누르는 동안만 3배로 동작합니다. 누르고 있는 동안에는 에일리언 경고·등장·전투, 부화장, 스테이지 전환, 게임오버, 다시 하기로 해제되지 않습니다. 일시정지·가이드에서는 진행을 멈춘 채 홀드 상태만 반영합니다. 키나 버튼을 놓으면 1배속으로 돌아오며, 창 포커스 이탈·탭 비활성화·터치 취소에도 입력이 남지 않게 처리합니다. 키보드와 버튼을 함께 누르면 둘 다 놓을 때 해제됩니다.

## 게임 규칙

- 구피는 **허기 또는 굶주림 상태에서만** 사료를 찾고 먹습니다. 식사 후 정상 상태에서는 먹이가 있어도 먹지 않습니다. 사료 **3개**를 먹으면 2/3 크기, **4개를 더 먹으면** 성체가 됩니다. 먹이를 가까이 떨어뜨려 주세요.
- 구피가 2/3으로 자라면 구피 구매와 사료 확장이 열립니다. 성체가 되면 알 구매가 열립니다. 피라냐는 1-2부터 성체 성장 후 구매할 수 있습니다.
- 구매한 구피는 화면 위에서 떨어져 물보라와 함께 입수한 뒤 헤엄칩니다. 입수 중에는 허기가 줄거나 사료를 먹지 않으며, 낙하와 입수 속도에도 개발용 배속이 적용됩니다. 시작할 때 주어지는 두 마리는 수중에서 시작합니다.
- 잠긴 물품은 슬롯 안에 아이콘·이름·가격·자물쇠가 모두 보이지 않습니다. 해금 후 잔액이 부족한 물품은 반투명하게 표시됩니다. 1-1의 피라냐는 항상 잠겨 있습니다.
- 상점의 구피는 버튼 너비 기준 오른쪽 7%, 알은 왼쪽 9%로 위치를 조정했습니다.
- 사료 확장 1회는 $100이며, 최대 9개까지 확장됩니다.
- 2/3 구피는 10초마다 은화($15), 성체는 금화($25)를 줍니다. 재화와 사료는 바닥에 도달하면 2초 후 사라집니다.
- 떨어지는 재화의 가로·세로 크기는 직전 버전의 3/4입니다. 은화·금화·보석은 78.75×78.75, 진주는 99×99 게임 좌표 픽셀이며 클릭 영역도 이에 맞춰 조정됩니다.
- 피라냐($1,000)는 배고플 때 **아기 구피만** 먹고, 15초마다 보석($500)을 만듭니다. 사료는 먹지 않습니다.
- 일반 물고기는 식사 후 10~15초에 배고파지고, 5초 뒤 초록색의 굶주림 상태가 됩니다. 그 뒤 7초 동안 먹지 못하면 죽습니다.
- 알 조각은 각 스테이지에서 **3회** 구매해야 완성됩니다. 조각당 가격은 1-1 $300, 1-2 $1,000, 1-3 $2,500입니다.
- 상점의 알 이미지는 **기본 1/3 → 1회 구매 후 2/3 → 2회 구매 후 3/3**으로 바뀝니다. 세 번째 구매 시 부화장으로 이동합니다. 목표의 구매 횟수 표시는 이미지 단계와 별도로 0/3회부터 셉니다.
- 우측 알 구매 목표 창은 1-1에서는 알이 해금된 후에 표시되며, 1-2와 1-3에서는 시작부터 표시됩니다.
- 1-1 완료 시 조개, 1-2 완료 시 청새치를 만납니다. 부화 후 **다음 바다로**를 누르세요. 1-3을 완료하면 엔딩입니다.
- 다음 스테이지에서는 $100, 아기 구피 2마리, 사료 상한 3개로 새로 시작하며, 획득한 펫이 함께합니다.
- 조개는 20초 대기 → 1초 열기 → 5초 동안 진주($350) 표시 → 1초 닫기를 반복합니다. 놓친 진주는 사라집니다.
- 조개의 기본 반복과 개폐 애니메이션은 이전의 절반 속도입니다. 닫힌 조개와 부화장 보상 조개는 `Clam_Default.png`의 9개 프레임을 3.5fps로 반복합니다. 구피·피라냐의 사망 이미지는 이미 상하반전된 원본을 사용하며 추가로 뒤집지 않습니다.
- 1-2부터 게임 내 시간 60초마다 에일리언 포탈이 열립니다. 5초 전 경고가 표시됩니다. 포탈·전투 중에는 사료 생성, 물고기의 허기, 구피의 은화·금화 생산 타이머가 멈춥니다. 처치 후 구피 생산은 남은 시간부터 이어지며 피라냐·조개의 생산과 기존 재화 수집은 계속 가능합니다. 개발용 홀드 배속도 유지됩니다.
- 에일리언의 체력은 30입니다. 청새치는 접촉 중 1초마다 체력 3을 깎습니다. 플레이어 클릭 피해는 1입니다. 구피와 피라냐를 모두 잃으면 게임오버입니다.
- 에일리언 표시·클릭 영역은 가로·세로 30% 커진 226.2×223.6 게임 좌표 픽셀입니다.

## 음원

`Sounds/`의 MP3 9개를 사용합니다. 배경음은 반복 재생하며, 에일리언 포탈이 열리면 전투 음악으로 바뀌고 적이 사라지면 일반 음악으로 돌아옵니다. 일시정지·가이드·탭 전환 시 음악도 멈추며, 다시 플레이하면 이어집니다. 개발용 배속을 바꿔도 음원의 재생 속도는 유지됩니다.

배경음 볼륨은 0.125입니다. 재화 획득·UI 클릭·에일리언 피격 효과음은 기존 0.7의 절반인 0.35, 다른 효과음은 0.7입니다.

## 검증

Node.js가 설치되어 있다면 다음 명령으로 테스트할 수 있습니다. 게임 실행에는 Node.js가 필요하지 않습니다.

```sh
node --test tests/game.test.cjs tests/audio.test.cjs tests/input.test.cjs
```

31개 테스트에서 성장·허기·먹이 중복 소비 방지·재화 중복 획득 방지·사료 상한·피라냐 먹이 제한·에일리언·펫·부화·재시작·일시정지·정상 상태의 식사 차단·해금 조건·알 이미지 단계·개발용 홀드 배속과 해제·구피 입수·부화 효과음 시점·음원별 볼륨·전투 중 구피 생산 정지와 재개·조개 개폐 시간을 검사합니다. 캠페인 테스트는 재화를 임의로 추가하지 않고 실제 시작 조건부터 정상 먹이·구매·수집·공격만 사용해 1-3 엔딩까지 진행합니다. 기준 시뮬레이션의 게임 내 시간은 약 13분 9초이며, 실제 플레이 시간은 조작과 배속 사용에 따라 달라집니다.

선택적 브라우저 미리보기:

```sh
node tests/preview.cjs
```

그런 다음 `http://127.0.0.1:4173`을 여세요. 이 도구는 현재 컴퓨터에서만 접속 가능하며 게임 HTML·CSS·JavaScript·이미지·MP3만 제공합니다. 종료는 `Ctrl+C`입니다. 게임에 필요한 서버 기능은 없습니다.
