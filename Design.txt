Popcap 게임즈의 구피 키우기 게임 Insaniquarium Deluxe를 참고한
웹미니게임(HTML, CSS, Javascript)을 제작하기
제작 기간 2시간, 플레이 타임 10분 내외

게임 구성
1-1, 1-2, 1-3 스테이지 존재
게임 시작 즉시 스테이지 진입
기본 재화 100$
시작 시 기본 1/3 크기의 허기 상태 구피 두 마리 제공
기본적으로 구매 물품은 모두 잠겨있음
(1-1 한정) 하단에, 화면을 눌러 구피에게 사료를 먹이라는 튜토리얼 메시지 표시
구피가 하나라도 2/3 상태가 되면 구피, 먹이 수 상한 해금
구피가 하나라도 3/3 상태가 되면 (1-2 부터)피라냐, 알 해금
모든 구피 및 피라냐가 굶주림 또는 잡아먹힘 등으로 사망 시 게임오버
게임오버 시 '게임오버!' 알림 오버레이 아래 다시 하기 버튼이 표시

UI 구성
스테이지
배경: 푸른 수족관 사이드뷰
상단: 구매 가능한 물품, 좌측부터
구피(1/3 크기 100$)
사료 수 상한(기본값 3, 1증가 당 100$, 최대 9)
피라냐(1000$)
알(기본값 1/3, 3회 구매 필요, 구매 당 (1-1) 750$ / (1-2) 1500$ / (1-3) 2500$)
우상단: 획득 재화량 (200$ 등) 표기
좌하단: 스테이지 정보 (1-1 등) 표기
중앙하단: 튜토리얼 설명, 에일리언 등장 전 주의 등 메시지
알 해금
배경: 부화장
1-1, 1-2: 알이 깨지며 펫이 등장하는 연출
1-3: 게임 엔딩 메시지

개체 구성
구피
수족관을 무작위로 헤엄치며 이동
제자리를 헤엄치거나 임의의 위치로 천천히, 또는 중간 속도로 이동
10-15초 정도마다 허기 상태 진입(기본 상태와 시각적 차이는 없음)
5초 뒤 굶주림 상태 진입, 굶주림 상태에서 7초 후 사망
굶주림 상태 (녹차색)
이동 상태는 기본적으로 변화없으나 수족관 내 사료 존재 시 빠르게 이동
사료 섭취 시 기본 상태 진입
사망 상태 (흰색)
더이상 자율적으로 움직이지 않으며 뒤집어진 채 천천히 가라앉음
수족관 바닥에 위치 시 페이드되며 사라짐
배고픔 정도와 별개의 성장 상태 존재 (1/3 크기, 2/3 크기, 성체)
2/3 크기부터 은화, 성체 크기에 금화를 주기적(10초) 드롭
1/3 크기에서 2/3 크기로 변하는 데 필요한 사료 수 3
2/3 크기에서 성체로 변하는 데 필요한 사료 수 4

재화
은화(15$), 금화(25$), 보석(200$), 진주(350$) 존재
생성 즉시 천천히 가라앉으며 수족관 바닥에 위치 시 페이드되며 사라짐
마우스로 클릭 시 재화 획득, 우상단 재화량 UI로 빠르게 이동하며 사라짐

사료
마우스로 상단, 우재화가 아닌 배경 클릭 시 5$를 소비하며 생성
생성 즉시 천천히 가라앉으며 수족관 바닥에 위치 시 페이드되며 사라짐
수족관에 동시 존재 가능한 상한 존재

피라냐
구피와 동일한 이동 메커니즘
구피와 동일한 굶주림 메커니즘
단 사료 대신 1/3 크기 구피 섭취
성장 메커니즘은 없으며 보석을 주기적 드롭

에일리언
1-2, 1-3 스테이지부터 등장 (5초 전 화면 하단에 에일리언 등장 주의 문구 표시)
1분마다 수족관 내 임의 위치에 포탈을 넘어 나타남
구피를 종류 구분없이 먹으며 빠르게 이동
구피와 닿으면 해당 구피는 즉시 잡아먹힘
30체력, 마우스로 클릭 시 1피해
에일리언 위치 마우스 클릭 위치 delta에 의한 이동방향 전환 기믹 존재
에일리언이 가고자 하는 방향으로 클릭시 작은 넉백 적용, 누적될 시 반대 방향으로 회피
에일리언이 존재하는 동안 구피들의 굶주림 정도가 변하지 않음
에일리언이 존재하는 동안 배경 클릭 시 사료를 생성하지 않음

펫
1-1 알: 조개, 1-2 스테이지부터 자동 등장
수족관 바닥 무작위 위치에 고정
20초마다 5초 간 입을 벌리는 모습과 함께 진주 생성, 진주는 조개 위치에 고정
진주의 획득 유무에 관계없이 5초 후 입을 닫으며 진주 미획득 시 진주 삭제됨
1-2 알: 청새치, 1-3 스테이지부터 자동 등장
구피와 동일한 이동 메커니즘, 굶주림 상태 없음
에일리언 등장 시 빠르게 이동하여 에일리언 공격, 별도 넉백 효과 없음
닿는 동안 1피해 (공격 주기 1초)
1-3 알: 엔딩

조작 구성
마우스 클릭: 물품 구매, 재화 획득, 사료 생성 등
스페이스바: 배속 기능(4x 배속)
